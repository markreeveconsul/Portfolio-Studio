# Platform icons

GitHub, Facebook, Instagram, YouTube, X, and TikTok SVGs were downloaded from Simple Icons via https://cdn.jsdelivr.net/npm/simple-icons@v16/icons/ on 2026-10-08. Individual filenames match the platform slug. Upstream: https://github.com/simple-icons/simple-icons. Brand marks belong to their respective owners. These files are bundled locally; viewing a portfolio does not contact a logo service. LinkedIn uses a local text badge and unknown websites use a local globe SVG in PlatformIcon.tsx.
