# Classmate usability test

Allow about 10 minutes per person. Ask permission before recording or taking screenshots. Use fictional portfolio information and a non-sensitive image. Never record passwords.

## Tasks

1. Sign in and start your portfolio.
2. Add a name, short introduction, and location. Save your changes.
3. Add a photo and confirm it has saved.
4. Add one skill or project, open the preview, and choose a template.
5. Return to edit, change something, save, and reload to check it persisted.

Let the tester try without coaching. If they get stuck, note where before helping.

## Record

Device/browser: ______
For each task: completed unaided / needed help / could not complete.
Where did the tester hesitate or click the wrong thing? ______
Was it clear when information, photos, and templates were saved? ______
Any clipped content, hard-to-tap controls, or unexpected scrolling? ______
Ease of use (1 difficult–5 easy): ______
What should we change first? ______

Use these observations to prioritize failures and confusing steps before cosmetic preferences.
