# User and administrator guide

Open https://myfolio-studio.vercel.app/ in a browser.

## Owner

Create and confirm an email/password account, or use Continue with Google. Sign in to open My portfolio. Fill in your full name and any optional contact details, introduction, social links, education, skills, projects, and experience. Save changes writes to Supabase and keeps the editor open. Save & continue saves and opens the preview. Refresh to verify persistence.

To add a profile photo, first save all text changes. Return to Edit information if you are in preview. Choose a JPG, PNG, or WebP file up to 2 MB. Selection previews the image locally; Save photo uploads it. A disabled picker means the portfolio is not saved or has pending text changes. Mobile photos may exceed 2 MB or use HEIC, which the current uploader does not accept. The owner reports successful phone uploads. If tapping has no effect, save text first and retry in the phone browser; report the browser, device, and exact symptom if it persists.

Open View saved portfolio to preview Simple, Modern, Creative, Professional Résumé, or Project Showcase. Save template commits the selected design without changing your content. Only you and authorized admins can access the portfolio.

To remove a portfolio, open its saved preview, choose Delete my portfolio, type DELETE, and confirm. This is permanent for the portfolio, but your sign-in account stays active. Retry photo cleanup if the app reports a pending file deletion.

Forgot password is on the sign-in page. Request one email and use the latest link. Enter matching passwords with at least 12 characters. Back to sign in signs out the recovery session. Continue to my portfolio stays signed in.

## Administrator

Sign in normally with the account whose user ID was assigned in private.admin_users. Admin workspace appears after the role check succeeds. View portfolios and photos; other owners' data is read-only. Your own portfolio remains editable. Do not assign privileges based on a user's editable profile fields.

## Troubleshooting

Unsaved changes: save before previewing or changing photos. Stale version: copy any text you need, then reload the saved version. Failed or ambiguous save: reload before repeating the operation. Photo cleanup pending: retry the cleanup when the connection is restored. Missing reset link: request a fresh email. Database setup errors: contact the operator; do not disable access policies.


## Cebu address and phone fields

Country is Philippines. Select a city/municipality in Cebu, then click the barangay field and type to search. Choosing another city clears barangay and postal code. Street and postal code are optional. Existing legacy addresses stay unchanged unless you choose Use Cebu address fields. The portfolio preview shows only the selected city/municipality and country. Enter a Philippine mobile number or Cebu landline in the +63 phone field.
