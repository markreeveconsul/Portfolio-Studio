## How to add a report

Assign UX-002 onwards. Include steps, expected/actual behavior, device/browser and the release tested. Use anonymous tester codes (T01, T02), not passwords or private portfolio details. Merge duplicates while recording how many independent testers encountered them. If you cannot reproduce an issue, keep the original report and mark Needs details rather than dismissing it.

Priority: P0 = data loss or suspected private-data exposure; P1 = a core task cannot be completed; P2 = significant confusion or a usable workaround; P3 = cosmetic/copy polish.
Status: Open → Reproducing → Planned → Fixed locally → Deployed → Verified. Use Needs details when reproduction information is missing. A local fix is not yet a verified deployed fix.
